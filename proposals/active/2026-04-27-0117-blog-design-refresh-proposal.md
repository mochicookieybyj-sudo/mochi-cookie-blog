# 블로그 디자인 개선 제안서

## 목적

현재 GitHub Pages에 배포된 최소 Jekyll 블로그 디자인을 더 세련되고 읽기 좋은 개인 기술 블로그 형태로 개선한다.

## 현재 상태

- 블로그는 GitHub Pages에 배포되어 있다.
- 주소는 `https://mochicookieybyj-sudo.github.io/mochi-cookie-blog/`이다.
- 현재 디자인은 최소 레이아웃과 기본 CSS 중심이다.
- 테스트 포스트 1개가 존재한다.

## 디자인 방향

차분하고 정돈된 개인 기술 블로그 스타일을 목표로 한다.

- 과한 랜딩 페이지식 장식은 피한다.
- 글을 읽고 찾는 경험을 우선한다.
- 운영 기록, 프로젝트 회고, AI 작업 로그를 담기 좋은 분위기로 만든다.
- 색상은 단조로운 한 가지 계열로 몰리지 않게 구성한다.
- 모바일에서도 글 목록과 본문이 안정적으로 읽히게 한다.

## 개선 범위

### 공통 레이아웃

- 헤더에 Home, Posts, About 링크를 추가한다.
- 전체 폭과 본문 폭을 정리한다.
- 상단에 블로그 이름과 짧은 설명을 배치한다.
- 푸터에 repo/운영 정보를 둘 수 있는 공간을 만든다.

### 홈 화면

- 최신 글 목록을 카드가 아닌 간결한 리스트 형태로 정리한다.
- 각 글에 날짜, 제목, 설명, 태그를 표시한다.
- 아직 글이 적어도 비어 보이지 않도록 첫 화면 구성을 보완한다.

### 포스트 화면

- 제목, 날짜, 태그, 설명이 명확하게 보이도록 정리한다.
- 본문 줄 길이, 줄간격, 제목 간격을 개선한다.
- 코드 블록, 인용문, 목록, 링크 스타일을 정리한다.

### 추가 페이지

- `posts` 목록 페이지를 만든다.
- `about` 페이지를 만든다.

## 구현 대상 파일

예상 수정/추가 파일:

- `site/_layouts/default.html`
- `site/_layouts/post.html`
- `site/assets/css/main.css`
- `site/index.md`
- `site/posts.md`
- `site/about.md`

## 검수 기준

- GitHub Actions build/deploy가 성공해야 한다.
- 공개 URL이 `200 OK`로 응답해야 한다.
- 홈 화면에서 최신 글이 읽기 좋게 보여야 한다.
- 포스트 본문이 모바일/데스크톱에서 모두 자연스럽게 읽혀야 한다.
