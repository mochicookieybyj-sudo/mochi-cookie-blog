# Writing Guide

## Source Draft Minimum Format

```yaml
---
title: ""
date: "YYYY-MM-DD"
source_project: ""
source_ai: ""
status: "draft"
tags: []
---
```

Required body sections:

- Summary
- Work Log
- Result
- Issues or Limitations
- Reference Links

## Publish-Ready Post Metadata

```yaml
---
layout: post
title: ""
description: ""
date: "YYYY-MM-DD"
updated: "YYYY-MM-DD"
tags: []
series: ""
source_project: ""
source_ai: ""
status: "review"
---
```
