# Workflow

## Implementation Changes

1. Write or update a proposal.
2. Keep user-answer-needed items at the bottom.
3. Wait for explicit implementation approval.
4. Implement the approved scope.
5. Record post-implementation notes in the same proposal.
6. Mark the proposal complete only when the user declares completion.

## Post Publishing

1. Receive source draft in `inbox/ai-drafts/`.
2. Preserve the source draft.
3. Create a publish-ready version under `content/posts/`.
4. Add related links, backlinks, tags, and series metadata.
5. Preview through the local Jekyll site.
6. User performs final review.
7. Push approved content to GitHub.
